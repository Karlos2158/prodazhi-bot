# Бот учёта продаж магазина при санатории

Telegram-бот принимает фото кассовых чеков, распознаёт позиции, сопоставляет их
с Excel-номенклатурой, спрашивает подтверждение только по нечётким совпадениям
и собирает дневные и месячные Excel-отчёты с зарплатными колонками.

Работает **только под Windows**. Python 3.12, `openpyxl` + `Pillow`;
Telegram вызывается через `urllib` без фреймворков. Распознавание — локальное
(Ollama + `qwen2.5vl:7b`), поэтому бот не зависит от внешних платных API.

## Где всё лежит

Репозиторий **и есть** рабочая папка бота — на вычислительной машине **SPQR**:

| Что | Где лежит |
|---|---|
| Код бота и конфиги | `G:\prodazhi-bot\` |
| Данные (номенклатура, чеки, отчёты) | `G:\prodazhi-bot\2026\` |
| Лог | `G:\prodazhi-bot\bot.log` |
| Git | тот же каталог `G:\prodazhi-bot` (репозиторий GitHub) |
| Автозапуск | папка автозагрузки SPQR, `sanator_bot.vbs` |

Запуск вручную: `G:\prodazhi-bot\run_bot.bat` (цикл перезапуска, `python -u bot_main.py`).
Второй экземпляр с тем же токеном запускать нельзя — Telegram отдаёт обновления только одному.

## Секреты

Настоящий `bot_config.json` содержит токен бота и ключ Gemini, поэтому:

- он **не хранится в репозитории** (см. `.gitignore`);
- в репозитории лежит только шаблон `bot_config.example.json`;
- при развёртывании конфиг копируется отдельно и вручную;
- перед каждым коммитом запускается проверка `tools/secret_scan.ps1` — она ищет
  в изменениях токены и ключи и блокирует публикацию.

## Данные магазина

Папка `2026/` (фото чеков, `data.json`, дневные и месячные xlsx, номенклатура)
в репозиторий не попадает: это личные данные, и они меняются каждый день.
`data.json` — единственный источник истины, отчёты собираются из него.

## Версии и публикация

Каждое изменение бота публикуется одной командой (на SPQR):

```powershell
powershell -ExecutionPolicy Bypass -File tools\publish.ps1 -Message "Что изменили"
```

Скрипт: проверяет изменения на секреты → делает коммит → ставит следующий тег
(`v1.3`, `v1.4`, ...) → отправляет `main` и теги на GitHub. Старые версии остаются
в истории и тегах, поэтому отдельные бэкапы на компьютере не нужны.

Откатиться на прошлую версию: `git checkout v1.0` (или `git show v1.0:bot_main.py`).
