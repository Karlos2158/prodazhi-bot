# Бот учёта продаж магазина при санатории

Telegram-бот для продавца: принимает фото кассовых чеков, распознаёт позиции,
сопоставляет их с Excel-номенклатурой и собирает дневные и месячные отчёты
в Excel (14 колонок, включая зарплатные). Вопросы задаёт только по нечётким
совпадениям — точные позиции проходят молча.

Работает **только под Windows**. Нужны Python 3.11–3.12 и Ollama с моделью
`qwen2.5vl:7b` — распознавание идёт локально, платные API не обязательны.
Telegram вызывается напрямую через `urllib`, фреймворки не нужны.

## Что должно быть установлено на компьютере

| Программа | Версия | Откуда скачать | Зачем |
|---|---|---|---|
| **Windows** | 10 или 11 | — | бот работает только под Windows |
| **Python** | 3.11 или 3.12 | [python.org/downloads](https://www.python.org/downloads/) → «Windows installer (64-bit)» | запуск бота |
| **Ollama** | любая актуальная | [ollama.com/download](https://ollama.com/download) → Windows | локальное распознавание чеков |
| **Модель `qwen2.5vl:7b`** | — | ставится командой (см. ниже) | читает фото чеков, ~6 ГБ |
| **Пакеты Python** | — | `python -m pip install openpyxl Pillow` | Excel и обработка картинок |

При установке Python **обязательно** поставьте галочку **«Add python.exe to PATH»** —
иначе `run_bot.bat` не найдёт Python.

Скачивание модели (один раз, ~6 ГБ):

```bat
ollama pull qwen2.5vl:7b
```

Проверка, что всё готово (открыть «Командную строку» и ввести):

```bat
python --version
python -m pip show openpyxl
ollama list
```

В ответе `ollama list` должна быть строка `qwen2.5vl:7b`.

## Порядок установки

### Шаг 1. Скачать бота

На странице репозитория — зелёная кнопка **Code → Download ZIP**.
Либо раздел **Releases** → у последней версии **Source code (zip)**.

### Шаг 2. Распаковать архив

Распакуйте в папку **без пробелов и кириллицы** в пути, например:

```
C:\prodazhi-bot
```

Эта папка — рабочая папка бота: в ней лежат `bot_main.py`, `run_bot.bat`
и будут созданы папки с данными.

### Шаг 3. Создать бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather), нажмите **Start**.
2. Отправьте `/newbot`.
3. Придумайте имя бота (например «Продажи Лесная Поляна»).
4. Придумайте адрес — он должен заканчиваться на `bot` (например `lesnaya_prodazhi_bot`).
5. BotFather пришлёт **токен** вида `123456789:AAH...`.

Токен — это пароль от бота. Никому не пересылайте, в переписку не вставляйте.

### Шаг 4. Создать файл настроек

В папке бота скопируйте `bot_config.example.json` в **`bot_config.json`**
(именно с точкой, без «example») и откройте блокнотом. Минимум, что нужно
заполнить:

```json
{
  "bot_token": "сюда_токен_от_BotFather",
  "root": "C:\\prodazhi-bot",
  "invite_code": "придуманный_код",
  "vision_engine": "local",
  "vision_model": "qwen2.5vl:7b"
}
```

- `root` — путь к папке бота **через два обратных слеша** (`\\`).
- `invite_code` — код, который бот один раз спросит у продавца
  (защита от посторонних). Придумайте любой.
- Остальные поля можно не трогать.

### Шаг 5. Положить номенклатуру

Скопируйте Excel-файл номенклатуры (`.xlsx`) в папку **`Номенклатура`**
внутри папки бота. Папка создастся сама при первом запуске — можно сразу
положить файл в корень `C:\prodazhi-bot`, бот его тоже найдёт.

### Шаг 6. Запустить

Двойной клик по **`run_bot.bat`**. Откроется чёрное окно, в нём будет:

```
бот запущен, модель: qwen2.5vl:7b
папка данных: C:\prodazhi-bot\Отчеты\2026
папка данных: C:\prodazhi-bot\Номенклатура\Ном 2026\Ном 11
номенклатура: C:\prodazhi-bot\Номенклатура\Номенклатура.xlsx
```

Окно не закрывать — пока оно открыто, бот работает. Всё, что происходит,
пишется в `bot.log` в той же папке.

### Шаг 7. Начать работу в Telegram

Найдите своего бота по адресу, который дал BotFather, нажмите **Start**,
введите код доступа (`invite_code`) — появится клавиатура.

Готово. Дальше — фото чека и кнопки.

## Папки: что создаёт бот, а что кладёте вы

Бот работает от **корня** (`root` в `bot_config.json`) и сам создаёт всю
структуру под текущий год и месяц. Следить за календарём не нужно: в декабре
появятся папки `Ном 12`, в январе — `Ном 2027\Ном 01`, и так далее.

```
C:\prodazhi-bot\                      ← папка бота (распаковали архив)
│
├── bot_main.py, run_bot.bat, bot_config.json ...
│
├── Номенклатура\                     ← бот создаёт сам
│   └── Ном 2026\                     ← год
│       ├── Ном 11\                   ← ноябрь: сюда можно класть номенклатуру месяца
│       │   ├── Номенклатура ноября.xlsx
│       │   └── план.json             ← план месяца (бот пишет сам)
│       ├── Ном 12\                   ← декабрь (создастся сам)
│       └── Ном 2027\Ном 01\          ← январь следующего года (создастся сам)
│
├── Отчеты\                           ← бот создаёт сам
│   └── 2026\                         ← год
│       ├── 11\                       ← ноябрь
│       │   └── 13.11.2026\           ← день: фото чеков + data.json + дневной Excel
│       ├── 12\                       ← декабрь (создастся сам)
│       └── _отчёты\                  ← сводные отчёты за период
│
└── bot.log                           ← лог работы
```

**Кладёте руками только номенклатуру.** Всё остальное (папки по годам,
месяцам, дням, `data.json`, отчёты, `план.json`) бот делает сам.

### Куда именно класть номенклатуру

Любой из вариантов — бот найдёт файл:

1. **`C:\prodazhi-bot\Номенклатура\`** — общая папка для файлов номенклатуры;
2. **`C:\prodazhi-bot\`** — прямо рядом с ботом;
3. `Номенклатура\Ном 2026\Ном 11\` — если хотите раскладывать по месяцам.

Правило выбора: бот берёт **самый свежий по дате изменения** файл `.xlsx`/`.xls`.
Если положили новую выгрузку — она подхватится автоматически, даже
перезапускать бота не нужно. Переименовывать файлы не надо: при одинаковой
дате «`Номенклатура (2).xlsx`» считается новее, чем «`Номенклатура.xlsx`».
Если в папке текущего месяца пусто (например, только начался новый месяц),
бот возьмёт последнюю загруженную номенклатуру — работать можно сразу,
а новую выгрузку достаточно положить в папку бота.

Номенклатура **только читается** — бот никогда не изменяет ваш Excel.

## Кнопки бота: за что отвечают и когда нажимать

| Кнопка | Что делает | Когда нажимать |
|---|---|---|
| 📊 **Отчёт за день** | собирает Excel за день (все чеки дня) и присылает файлом в чат | в конце рабочего дня, после того как все чеки отправлены |
| 📅 **Отчёт за период** | сводный Excel за месяц или любой период; пересчитывает по самой свежей номенклатуре | в конце месяца, для сверки, или когда нужен отчёт за несколько дней |
| ✏️ **Правка позиций** | меняет название, категорию, количество или цену в уже принятом чеке | если бот неверно сопоставил товар, если ошиблись категорией/оплатой |
| 🗑 **Удалить отчёт** | удаляет ошибочно загруженный чек из дня | если чек отправлен дважды или это чужой/тестовый чек |
| ⚙️ **Настройки** | показывает проценты категорий и план; принимает команды изменения | когда нужно изменить проценты зарплаты или план на месяц |
| 📖 **Инструкции** | присылает файл инструкции для продавца | для нового продавца или если забыли порядок работы |
| 🔄 **Модель: локальная / Gemini** | переключает движок распознавания | если локальная модель не справляется или наоборот недоступен Gemini |
| **Вывод / Матрица / Новинка** | ответ на вопрос бота о категории позиции | когда бот спросил «К какой категории отнести?» |
| **Нал / Карта** | ответ на вопрос об оплате | когда бот спросил, как оплачен чек |
| **Перемещение / Не перемещение** | ответ: товар перевезён с другой точки или нет | когда бот спрашивает про перемещение |

Команды в чат (набираются текстом):

- `план 1500000` — план продаж на текущий месяц;
- `вывод 5`, `матрица 4`, `новинка 3` — проценты зарплаты по категориям;
- `план выполнен 5`, `план не выполнен 4` — надбавка при выполнении/невыполнении плана.

## Как проходит обычный день

1. Продавец фотографирует чек (целиком, ровно, без бликов) и отправляет боту.
2. Бот распознаёт дату, время, товары, суммы и оплату. Дата берётся **с чека**,
   поэтому опоздавший чек попадёт в свою дату.
3. Если позиция совпала с номенклатурой точно — вопросов нет. Если похоже,
   но не точно — бот спрашивает категорию (и иногда оплату).
4. Чек сохраняется в `Отчеты\<год>\<ММ>\<ДД.ММ.ГГГГ>\data.json`, фото — рядом.
5. В конце дня — кнопка **📊 Отчёт за день**, файл приходит в чат и лежит
   в папке дня.
6. В конце месяца — **📅 Отчёт за период**.

`data.json` — главный источник данных: дневные и месячные Excel собираются
из него, поэтому удалить старый `.xlsx` безопасно (он пересоберётся).

## Распознавание: локально или Gemini

**Локально (по умолчанию, рекомендуется).** Ollama на этом же компьютере,
модель `qwen2.5vl:7b`. Бесплатно, работает без интернета (кроме Telegram).
Нужно ~6 ГБ свободной видеопамяти/ОЗУ. Если модель не влезает в память,
Ollama вернёт ошибку `out of memory` — закройте лишние программы.

**Gemini (по желанию).** Нужен ключ из [Google AI Studio](https://aistudio.google.com/)
в поле `gemini_api_key`. Бесплатная квота модели `gemini-2.5-flash` —
**20 запросов в сутки**; после исчерпания приходит ошибка 429 и распознавание
не работает до сброса квоты. Переключение — кнопкой `🔄 Модель: …`, без правки файлов.

Если прямой доступ к Google блокируется, в конфиге можно указать
`gemini_relay` — адрес простого HTTP-релея в своей сети, который сам добавляет
ключ. Тогда `gemini_api_key` на рабочем компьютере не нужен.

## Автозапуск

Чтобы бот поднимался сам после перезагрузки:

1. `Win+R` → введите `shell:startup` → Enter.
2. Положите в открывшуюся папку ярлык на `run_bot.bat`.

`run_bot.bat` перезапускает бота при сбое и пишет лог в `bot.log`.
**Второй экземпляр с тем же токеном запускать нельзя** — Telegram отдаёт
обновления только одному процессу, и боты начнут «съедать» сообщения друг друга.

## Настройки (`bot_config.json`)

| Поле | Обязательно | Что это |
|---|---|---|
| `bot_token` | да | токен от @BotFather |
| `root` | да | корень данных, например `C:\\prodazhi-bot` |
| `allowed_chats` | нет | список ID чатов; пусто = доступ по коду |
| `invite_code` | нет | код доступа для нового чата |
| `vision_engine` | нет | `local` (Ollama) или `gemini` |
| `vision_model` | нет | для локального — `qwen2.5vl:7b` |
| `ollama_url` | нет | по умолчанию `http://127.0.0.1:11434` |
| `gemini_api_key` | только для Gemini | ключ Google AI Studio |
| `gemini_model` | нет | по умолчанию `gemini-2.5-flash` |
| `gemini_relay`, `gemini_relay_token` | нет | релей Gemini, если он в своей сети |
| `проценты_категорий` | нет | проценты зарплаты: `Вывод`, `Матрица`, `Новинка` |
| `home_point`, `points` | нет | точки/склады для кнопки «Перемещение» |

`bot_config.json` — живой файл: бот переписывает его, когда модель
переключают кнопкой или меняют настройки в чате. Правки руками — только
при остановленном боте.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Окно `run_bot.bat` мгновенно закрылось | не установлен Python или не стоит галочка «Add to PATH»: `python --version` в командной строке |
| Бот молчит | запущен второй экземпляр с тем же токеном или неверный токен. Закрыть все окна, проверить токен, запустить заново |
| `номенклатура: НЕ НАЙДЕНА` | файл не `.xlsx`/`.xls`, лежит не в папке бота, либо это временный `~$файл.xlsx` (закрыть Excel) |
| «Не смог распознать чек» | Ollama не запущена или модель не скачана: `ollama list` → при отсутствии `ollama pull qwen2.5vl:7b` |
| Ollama: `out of memory` | модель не влезает в память: закрыть лишние программы или использовать Gemini |
| Ошибка 429 (Gemini) | кончилась суточная квота (20 запросов): ждать сброса или переключиться на локальную модель |
| `WinError 10060` / `read operation timed out` | нет связи с Telegram: проверить интернет/прокси; бот сам повторит попытку |
| В отчёте «не та» категория | кнопка ✏️ **Правка позиций** или обновить номенклатуру |
| Кракозябры в `bot.log` | лог в кодировке cp1251 — открывать в Notepad++ / VS Code с этой кодировкой |

## Секреты и приватность

В репозитории **нет** токена бота, ключей и данных магазина:

- `bot_config.json` (токен, ключи) — в `.gitignore`, в репозитории только
  шаблон `bot_config.example.json` с заглушками;
- папки `Отчеты/` и `Номенклатура/` в репозиторий не попадают;
- перед каждым коммитом `tools/secret_scan.ps1` ищет токены и ключи
  в изменениях и блокирует публикацию.

Поэтому код можно показывать кому угодно, а `bot_config.json`, папки данных
и `bot.log` пересылать нельзя.

## Для разработчика: версии и публикация

Репозиторий можно держать прямо в рабочей папке бота. Новая версия:

```powershell
powershell -ExecutionPolicy Bypass -File tools\publish.ps1 -Message "что изменили"
```

Скрипт проверяет изменения на секреты → делает коммит → ставит следующий тег
(`v1.5`, `v1.6`, …) → отправляет `main` и тег на GitHub → оформляет релиз.

Откатиться на прошлую версию: `git checkout v1.4` или посмотреть файл:
`git show v1.4:bot_main.py`.
