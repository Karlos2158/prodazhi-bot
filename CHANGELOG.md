# Журнал версий бота

Формат: версия — дата — что изменилось.

## v1.0 — 2026-11-11
- Бот перенесён с GHO на SPQR в `G:\SanatorBot`, данные — `G:\Sanator`.
- Отчёт за период собирается из `data.json` и пересчитывает все позиции
  по самой свежей номенклатуре (`fresh=True`).
- Номенклатура выбирается по времени изменения файла (`(2)` новее базового).
- Бренд-префикс (`VV`, `БМ`, `К`, ...) сохраняется при распознавании и обязателен
  при сопоставлении.
- Спрашивать подтверждение только по нечётким совпадениям; точные проходят молча,
  правка доступна кнопкой «✏️ Правка позиций».
- Распознавание: правило против склейки похожих строк (`VV Серьги` / `К Серьги`)
  и повторные попытки, если названия в чеке повторились.
- Устойчивость: длинный опрос Telegram с запасом по таймауту, устаревшие кнопки
  не роняют обработчик, автозапуск на SPQR поднимает WARP и бота.
